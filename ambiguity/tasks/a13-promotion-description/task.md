# Promotions get a description

Marketing wants every promotion to carry a short description that we can show to customers, such as "Summer sale on
all hardware", instead of only the bare promotion code. The description is entered when the promotion is set up and is
optional; older promotions simply have none. It must come back with the promotion everywhere promotions are listed: the
promotions active on a date, the active promotions of a region, the promotions of a category, the best promotion for a
category on a date, the unused promotions of a period, and when a promotion is looked up by its code. For example, the
SUMMER promotion created with the description "Summer sale on all hardware" shows that text in each of these, while a
promotion created without one shows no description.
