# Year-over-year comparison shows a false -100% average order value

In the year-over-year sales comparison per region, a region that had orders in a month last year but none in the same
month this year shows its average order value change as -100%. That is misleading: with no orders there is no average
order value to compare, and sales managers read the -100% as if the orders had become worthless. When the month has no
orders, the average order value change should be left empty, just as it already is when last year had no orders. The
revenue change (-100% in that case) and the figures of regions with orders in both years stay as they are; for
example, a region whose average order went from 20.00 to 40.00 still shows +100%.
