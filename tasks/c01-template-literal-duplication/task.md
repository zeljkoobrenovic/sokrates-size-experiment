Sokrates reports duplicated units (functions and methods whose bodies are the same once normalized) in the Duplication report's unit duplicates list. For that comparison the text inside string literals is already ignored: a double-quoted `"..."` or single-quoted `'...'` literal counts the same whatever it contains, so two functions that only differ in the text of a message they build are reported as one duplicated unit.

Backtick template literals (JavaScript/TypeScript `` `...` ``, with or without `${...}` interpolation) are not treated this way. Two otherwise identical JavaScript functions whose only difference is a word inside a template literal, e.g. `` `Hello alpha ${name}` `` versus `` `Hello beta ${name}` ``, are currently seen as different units and no unit duplicate is reported for them (unless the literal happens to contain slashes, which another normalization masks by accident).

Make template literals behave like the other string literals: their content must not count when units are compared for duplication, so that such functions are reported as one duplicated unit with both occurrences. A difference in the code outside the literals must still keep the units apart.
