In the landscape report, a repository whose name contains HTML characters (for example `acme <b>"shop"</b>`) breaks two tooltips of the landscape overview. In the per-language blocks of the "Lines of Code in Main Code" section (and the test/other code variants of it), hovering a language shows the repositories that have code in that language, and in the "Repositories Size Distribution" table hovering a size category shows the repositories in it with their lines of code. Both tooltips write the repository name into the page raw, so a quote in the name ends the tooltip early and the rest of the name leaks into the page as markup.

Make these two tooltips treat repository names as text: the hover text should show the full name exactly as configured (`acme <b>"shop"</b> (5,000 LOC)` in the language block, `acme <b>"shop"</b> 5000` in the size table), with no markup getting into the page. Nothing else about the tooltips (counts, lines of code, order, layout) should change.
