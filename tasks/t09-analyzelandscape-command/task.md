The Sokrates command line (`java -jar sokrates.jar <command> ...`) creates or refreshes a landscape report — the portfolio view aggregating the repository analyses found under an analysis root — with the `updateLandscape` command. Its name does not match the rest of the command vocabulary, so add `analyzeLandscape` as the documented name of the same command. Both names must dispatch to exactly the same behaviour with the same options (`-analysisRoot`, `-recursive`, `-confFile`, the metadata options, `-date`, `-timeout`, ...): running `analyzeLandscape -analysisRoot <folder>` creates `<folder>/_sokrates_landscape/config.json` and the landscape report (`index.html` next to it) just like `updateLandscape` does. `updateLandscape` stays, so existing scripts keep working.

`analyzeLandscape -help` prints the usage of the command the user typed (`java -jar sokrates.jar analyzeLandscape` with the landscape options and a description saying it is the landscape counterpart of the analysis commands and the same as `updateLandscape`), not the generic list of every command; `updateLandscape -help` keeps printing its own usage. The no-argument usage overview lists `analyzeLandscape` as well. Update the command descriptions in the README accordingly.
